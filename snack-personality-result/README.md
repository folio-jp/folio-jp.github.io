# 好きなお菓子からわかる12タイプ診断

好きなお菓子の自由入力とQ2〜Q10の固定選択肢から、12タイプ、5軸、TOP3構成をブラウザ内で算出する本番診断サイトです。診断開始から結果表示、全タイプ一覧、タイプ詳細までサイト内で完結します。回答や採点データはサーバーへ送信しません。

## ページURL

- 診断結果：`./?m=...`
- 診断案内：`./`（パラメータなし）
- 診断質問：`./quiz.html?q=1`
- 明示的なデモ：`./?demo=1`
- 全12タイプ一覧：`./types.html`
- タイプ詳細：`./type.html?id=T01`

結果ページは必須パラメータ`m`、`s`、`t`、`a`、`p`がすべて正常な場合だけ表示します。パラメータなしでは診断案内、不足・異常値では再取得案内を表示し、サンプル値へ自動補正しません。詳細ページの`id`は`T01`〜`T12`のみ許可します。

## 診断ロジック

- `quiz-data.js`がQ1〜Q10、配点、Q1分類辞書、同点処理、5軸基準値、TOP3正規化、結果URL生成を一元管理します。
- Q1は正本`source/01_お菓子分類辞書(1).md`を基準に、NFKC、英字大小、全半角、かな・カナ、空白・記号を正規化します。
- 商品名だけでなく、味・限定性・食感・濃厚さ・健康機能性・理由の順に修飾語を評価します。
- 未登録商品は診断を止めず、味と食感を各1問だけ追加確認して30点へ分類します。
- Q1は30点、Q2〜Q10は70点で、全回答の合計は必ず100点です。
- 1位と2位の差が1.5点未満の場合は、Q1〜Q4、Q5〜Q7、Q1直接一致度、類似タイプ基準の順に判定します。
- 5軸は全タイプ得点とタイプ基準値の加重平均を四捨五入します。
- TOP3だけを合計100%へ整数正規化し、丸め差分はメインタイプへ加減します。
- 生得点は結果画面と共有URLへ出しません。

## 回答状態

`quiz.js`が`localStorage`へ回答状態を保存します。再読み込み、途中離脱、ブラウザバックで復元されます。「回答を見直す」は保存状態を保持し、「もう一度診断する」は回答と完了状態を削除します。氏名、メールアドレスなどの個人情報は保存しません。

## URLパラメータ

| キー | 内容 | 形式 |
|---|---|---|
| `m` | メインタイプ | `T01`〜`T12` |
| `s` | サブタイプ | `T01`〜`T12` |
| `t` | 第3タイプ | `T01`〜`T12` |
| `a` | 好奇心、社交性、こだわり、安心志向、刺激欲求 | 0〜100の数値5個をカンマ区切り |
| `p` | メイン、サブ、第3タイプの構成比 | 0〜100の数値3個をカンマ区切り |
| `snack` | 好きなお菓子名 | URLエンコード済み文字列、最大40文字 |

`p`の合計が100でない場合は、比率を保ちながら整数の合計が100になるよう再正規化します。必須値の不足・不正値では結果を表示しません。ユーザー入力は`textContent`経由でのみDOMへ挿入します。

## キャラクター画像の管理

- `03_キャラクター対応表(1).md`記載のID・キャラクター名・推奨ファイル名を正本とします。
- 診断ごとに画像を生成せず、`assets/`内の確定PNGのみを使います。
- 別タイプの画像を代用しません。
- 画像の色、服装、小物、構図を改変しません。
- 画像を差し替える場合も、対応するタイプIDとファイル名を維持します。

## 更新時の注意点

- タイプ名、キャラクター名、本文、相性、カラーは`source/`の正本を変更してから`npm run build:data`を実行します。
- 一覧・詳細用のタグ、補助分類、お菓子スタイル、似ているタイプも`build-data.mjs`から同じ`types.js`へ生成し、ページ別データを作りません。
- `types.js`は自動生成物のため直接編集しません。
- 一言コピーが対応表と結果文章で一致しない場合、生成処理は失敗します。
- 12タイプ未満、無効な相性ID、対応表不足も生成エラーになります。
- 更新後は必ず`npm test`、375px・390px・430px・768px・1440pxの表示、印刷プレビュー、共有URLを確認します。
- Q2〜Q10の文章・選択肢・配点は固定仕様のため、変更時は正本との全文一致テストも同時に更新します。
- Q1辞書を変更した場合は、代表商品・表記揺れ・未知商品フォールバック・30点合計を再検証します。
- ベースURLで結果が表示されないこと、`?demo=1`でだけデモ結果が表示されることも確認します。
- 診断を正式な心理検査・医療診断として表現しません。
